# 设备异常日历（anomaly_calendar）

异常 / 停机 / 维护日历类材料。三类来源已入库。

## 来源时间线

| 阶段 | 介质 | 说明 |
|------|------|------|
| ~2018（2019 年前） | `.et` / `.xls` 事报表 | 仪器专业组「区域每周设备管理汇总」→ **气体类** 周条目 |
| 2019 起（群晖） | `.ics` | 区域调整后气体日立分散在多个日历；主源 **气体类区域** |
| 约 2020 起（WPS） | rili.wps.cn「化学区域」 | 见已有 `wps_rili_*` 导出 |

## 关注范围与称呼约定

日志/日程标题**很少写仪器型号**，多用实验室内代号或泛称。

| 优先级 | 说明 |
|--------|------|
| P0 可采集 | **CS844**（碳硫）、**ON(H)836**（氧氮氢）——有数据采集接口 |
| P1 同族代号 | 二炼钢已联机：`GC6/7/8`、`GO6/7/9`（`lab-2lg`）；电炉 `GC2/3/4`、`ON1/2`；一炼钢 `CS2/3`、`ON2`、`ONH2` 等 |
| P2 泛称参考 | 「氧氮 / 碳硫 / 定氢 / 气体」——可能是上一代 **CS600 / TC(H)600 / CS444 / TC436** 等；型号不明也保留 |

处理规则：保留原文；另标代号 / tier；不因「可能是旧机」丢弃。
