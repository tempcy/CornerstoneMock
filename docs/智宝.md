### 4.2 配置迁移上传（已验证）

| 步骤 | API |
|------|-----|
| 导出 | `POST /api/developer/config-migration/export` body 含 `instanceCode`（可选 `agents`）→ `taskId` → `.../tasks/{id}/download` 得 zip |
| 预检 | `POST /api/developer/config-migration/import/preview` FormData：`file` + `targetInstanceCode` |

## 5. 对话任务（已验证）

创建 `POST /api/chat-tasks/{instanceCode}`  
轮询：`GET /api/chat-tasks/{taskId}`（可选 `?sinceSeq=`）  
取消：`POST /api/chat-tasks/{taskId}/cancel`

**请求体要点（错误格式会 503）：**

```json
{
  "input": [{
    "role": "user",
    "type": "message",
    "content": [{ "type": "text", "text": "用户话术" }]
  }],
  "session_id": "<uuid>",
  "chat_id": "",
  "user_id": "default",
  "channel": "console",
  "stream": true,
  "agent_id": "CornerstoneMock"
}
```

- `content` 必须是 **数组**（`[{type,text}]`），不能是纯字符串。  
- 可选头：`X-Agent-Id: CornerstoneMock`。  
- 上传文件走：`POST /proxy/{instanceCode}/api/console/upload`。
